# 积木拼搭

一个基于 Pygame、Orbbec Gemini2、OpenCV 和 MediaPipe 的体感益智拼搭游戏。孩子和家长通过手势抓取虚拟积木，按照目标轮廓完成图形拼搭。

## 当前玩法

- 初始界面选择关卡，完成上一关后解锁下一关。
- 共 5 关：
  - 第 1 关：认识图形，把正方形、长方形、三角形放到平台目标上。
  - 第 2 关：把三角形放到长方形上。
  - 第 3 关：搭建小房子。
  - 第 4 关：搭建一棵树。
  - 第 5 关：搭建小桥。
- 目标位置带容错，不需要完全对齐。
- 游戏中会显示半透明目标轮廓和完成进度。

## 手势

- 握拳：抓取积木。
- 张开手：释放积木。

## 相机稳定性

- 优先使用 Orbbec Gemini2 彩色流和深度流。
- 在低光环境下增强输入给 MediaPipe 的检测画面。
- 第一次检测到手后锁定这只手，并结合位置与掌心深度持续跟踪，减少其他手进入画面时的干扰。
- 如果 Orbbec 初始化失败，会尝试退回普通摄像头。

## 运行

```bash
python main.py
```

## 按键

| Key | Action |
| --- | --- |
| 1-5 | 在选关界面选择已解锁关卡 |
| Enter / Space | 从当前关卡开始 |
| Space | 游戏中暂停/继续 |
| R | 重玩当前关 |
| L | 返回选关 |
| N | 通关后进入下一关 |
| ESC | 退出 |

## 依赖

```bash
pip install pygame opencv-python numpy mediapipe
```

Orbbec Gemini2 需要安装 `pyorbbecsdk` 和对应驱动。
